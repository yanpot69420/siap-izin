TENTANG PILOT
Geometri nyata, batas bukti tetap jelas.
Frontend lokal dan API Python baca-saja untuk pilot Tirawuta. Tidak ada AI, login atau penginputan OSS. Sumber dibaca dari layanan publik tanpa kredensial; cache geometri privat tidak ikut repo.
Leaflet/OpenStreetMap dimuat setelah pilihan pengguna. Sumber geometri terpisah dari peta dasar. Ketentuan integrasi/publikasi produksi belum disahkan; pilot ini bukan izin distribusi ulang data.
Ringkasan delapan RDTR adalah audit historis; waktu pembacaan geometri pilot ditampilkan tersendiri. Pembuatan polygon rencana dan penilaian agronomi bukan fungsi modul ini.
